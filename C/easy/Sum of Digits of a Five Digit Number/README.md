
# Sum of Digits of a Five Digit Number

• Language : C

• Objective: To extract individual digits from an integer and calculate their total sum using arithmetic operations.

  • Task: Given a five-digit positive integer $n$, find the sum of its digits.Example: Input 10564 → $1+0+5+6+4$ → Output 16.

• Level: Easy
